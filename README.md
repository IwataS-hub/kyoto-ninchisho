# 京都府 認知症「かかりつけ医」検索

京都府内で認知症・もの忘れに対応する医療機関（病院・診療所）と、京都府が指定する
認知症疾患医療センターを地図上で検索できるWebアプリです。住所や現在地から
近い順に施設一覧を表示します（`index.html` を開くだけで動作する静的サイト）。

## データ出典

- 厚生労働省「[医療情報ネット](https://www.iryou-jouhou.jp/)」オープンデータ
  （病院・診療所の施設情報、診療科目情報）
- 京都府「きょうと認知症あんしんナビ」認知症疾患医療センター一覧
  （`kyoto_dementia_centers.csv`）

`clinics.geojson` は上記2つのデータを `build_geojson.py` で抽出・統合・名寄せして
生成しています。生成手順や抽出条件の詳細は `build_geojson.py` 冒頭のコメントを
参照してください。

## 免責事項

- 表示される移動距離は2点間の**直線距離からの概算**です。実際の道路距離・所要時間
  とは異なります。
- 施設情報は変更されることがあります。**受診前には必ず施設に電話でご確認ください。**
- 住所検索には国土地理院ジオコーディングAPIを利用していますが、入力された住所は
  保存されません。

## ライセンス

本アプリが利用するデータの著作権は各データ提供元（厚生労働省、京都府）に帰属します。
データを再利用・転載する場合は、出典として「厚生労働省 医療情報ネット」および
「京都府 きょうと認知症あんしんナビ」を明記してください。

## ローカルでの再生成

元データ（医療情報ネットの全国版CSV4ファイル）を本リポジトリのルートに配置した上で、

```sh
python3 build_geojson.py
```

を実行すると `clinics.geojson` を再生成できます。元データのCSVはサイズが大きいため
本リポジトリには含めていません（`.gitignore` 参照）。
