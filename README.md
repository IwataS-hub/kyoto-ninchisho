# 京都市 認知症「かかりつけ医」検索

認知症・もの忘れに対応する医療機関（病院・診療所）と、京都府が指定する
認知症疾患医療センターを地図上で検索できるWebアプリです。住所や現在地から
近い順に施設一覧を表示します（`index.html` を開くだけで動作する静的サイト）。

> **現在の対象範囲**: 京都市内にフォーカスしています（議事録2026-06-20の方針による）。
> 府全域版は `python3 build_geojson.py --scope pref` で再生成可能です
> （データの切り替えのみで、アプリ本体は両スコープで動作します）。

## AI相談機能（consult.html）

`consult.html` は、困りごとを入力すると生成AIが追加質問（最大8問）で内容を整理し、
緊急度（緊急/早め/通常）と相談先カテゴリ（救急・専門機関・もの忘れ外来・かかりつけ医・
地域包括支援センター）を提示する相談ページです。結果画面の「地図で見る」ボタンから、
`index.html` が適切なフィルタON状態で開きます（例: `index.html?flags=monowasure&stage=moderate`）。

### 進行度評価型問診エンジン（北川設計書に基づく）

AI相談は、チーム医療設計担当（北川）の設計書に基づく「進行度評価型の問診エンジン」で
動作します（実装は `worker/worker.js` のシステムプロンプト）。

- **回答者の確認と経路別の配慮**: 最初に「ご本人様でしょうか？ご家族でしょうか？」を確認し、
  本人経路では自尊心の保護を最優先した間接的な聞き方、家族経路では介護者への労いを挟みながら
  客観的な出来事を引き出す聞き方に切り替えます。
- **4段階問診（逆発生の順序）**: ①基本情報（年齢・同居・いつから）→ ②短期記憶とIADL
  （金銭管理・料理の段取り・買い物）→ ③季節に合った服選び・着衣 → ④入浴・排泄の自立度・
  自発性・発語量、の順に軽い段階から確認します。
- **危険兆候の差し込み質問**: 急性発症（せん妄疑い→救急案内）・顕著な行動心理症状
  （BPSD→専門機関＋レスパイトケア案内）・歩行の変化（可逆性疾患の疑い→鑑別診断の推奨）を
  常時監視し、確認質問を1問だけ差し込みます。
- **内部でのステージ推定**: 会話からFASTステージ相当の進行度を内部推定しますが、
  **推定値・病名・「認知症」の断定は利用者の画面に一切表示しません**。推定は
  (1) 地図リンクの `?stage=` パラメータ（対応施設の優先表示）と
  (2)「医療機関に伝えるメモ」（医療者が読む欄）の記載にのみ使います。
- **情報不足時のフェイルセーフ**: 具体的なエピソードが得られない場合は無理に推定せず、
  「正確な把握が難しいため、念のため相談をおすすめします」と慎重側（相談を促す方向）に倒します。

**ステージ推定はあくまで「目安」です。** 生成AIによる参考情報であり、医学的評価・診断では
ありません。地図側の優先表示・バッジにも必ず「目安」である旨を表示しています。

### 安全設計

- **診断はしません。** 病名の断定・薬剤や治療方針の提案は、Worker側システムプロンプトで
  禁止しており、「相談できる窓口の案内」に徹します。
- **危険兆候の二段階判定（`triage.js`）。** 語彙表と文脈判定はフロント（`consult.html`）と
  Worker で共通の `triage.js` に集約しています。

  | 区分 | 例 | フロントの挙動 |
  |---|---|---|
  | **緊急語** | 意識がない・反応がない・けいれん・呼びかけに応じない・ろれつが回らない | AIの応答を待たず救急案内バナーを即時表示 |
  | **要確認語** | ふらふら・転ぶ・急に・熱・頭を打った・ぼんやり | バナーは出さず、AIに確認質問を促すヒントを送るのみ |

  単独では要確認語でも、**組み合わせで緊急に格上げ**します。
  現在の格上げ規則は次の3つです。

  | 組み合わせ | 例 |
  |---|---|
  | 頭部打撲 ＋ 打撲後の変化 | 転んで頭を打ってから様子がおかしい |
  | 頭部打撲 ＋ 嘔吐 | 頭を打ってから吐いています |
  | 急な発症 ＋ 普段と違う様子 | 数日前から急にぼんやりして、呼びかけても反応が鈍い |

  「反応が鈍い」「ぼんやり」を単独で緊急語にはしません。認知症の進行に伴う
  ゆるやかな変化（「だんだん反応が鈍くなった」）まで緊急に振れてしまうためで、
  急性発症を示す語と同時に現れたときだけ緊急に格上げします。
  一方「反応がない／ありません」は程度ではなく有無を示すため、単独で緊急語です。

  緊急語の述語は活用形を機械展開しており、プレーン形（〜ない）だけでなく
  丁寧形（〜ません）・難易形（〜にくい／〜づらい）・テ形の否定（〜ていません）を
  拾います（「ろれつが回りません」「手足が動かしにくい」など）。
  また、否定（「熱はありません」）・過去（「1年前」「以前」）・仮定や不安
  （「転ぶかもしれないのが心配」）は発火させません。程度の表現（「少し」「たまに」）は
  抑制せず、重症度を上げすぎないためのヒントとしてAIに渡します。
- **「検知 → 確認質問1問 → 判断」の手順を強制。** 要確認語しか無いのにAIが緊急と結論した
  場合、Worker が結論を破棄して確認質問1問に差し替えます。緊急語に該当する場合と
  質問上限に達している場合はそのまま結論を通すため、緊急の見落としにはならず、
  判断が1問ぶん遅れるだけです。
- **症状の強さと緊急性を分けて判断。** 進行度（FAST相当）が中等度〜重度であることと、
  いま救急を要することは別である旨をシステムプロンプトに明記しています。
- **結果画面には常に**「本アプリは診断を行うものではありません。緊急時は119へ」を表示します。
- **入力内容は保存されません。** フロント・Workerともに相談本文を保存せず、
  サーバーログにも本文を残しません。

### モック / 本番の切り替え

`consult.html` は現在 **本番AIモード**（`CONFIG.MOCK: false`）で、`CONFIG.WORKER_URL` の
Cloudflare Worker 経由で Gemini API を呼びます。

ローカルで動作を確認したいときは、**localhost に限り** `?mock=1` を付けると内蔵ダミー応答
（Worker・APIキー不要）に切り替わります。本番（GitHub Pages）では無効です。

```sh
python3 -m http.server 8791
# → http://localhost:8791/consult.html?mock=1
```

初期構築時の本番切り替え手順:

1. Gemini APIキーを取得（https://aistudio.google.com/apikey ）
2. `worker/README.md` の手順でCloudflare Workerをデプロイ
   （`npx wrangler login` → `npx wrangler secret put GEMINI_API_KEY` → `npx wrangler deploy`）
3. `consult.html` 冒頭の `CONFIG.WORKER_URL` にWorkerのURLを設定し、`CONFIG.MOCK` を `false` に変更

APIキーはWorkerのsecretにのみ置き、リポジトリには含めません。

### 使用モデル

Gemini API の `gemini-3.7-flash`（安定版）を使用します。表現の機微（「ふらふらする」＝歩行の
不安定さ と「意識がもうろう」＝意識の障害 の区別など）の判別精度を優先し、
`gemini-3.1-flash-lite` から変更しました。料金・レート制限・コストの目安は
`worker/README.md` の「使用モデル」を参照してください。

## データ出典

- 厚生労働省「[医療情報ネット](https://www.iryou-jouhou.jp/)」オープンデータ
  （病院・診療所の施設情報、診療科目情報）
- 京都府「きょうと認知症あんしんナビ」認知症疾患医療センター一覧
  （`kyoto_dementia_centers.csv`）
- 京都府「きょうと認知症あんしんナビ」もの忘れ外来・認知症外来等を標榜する病院一覧
  のうち京都市内分（`kyoto_city_monowasure.csv`）。名寄せで既存施設と統合し、
  該当施設を「専門」・もの忘れ外来として表示

`clinics.geojson` は上記2つのデータを `build_geojson.py` で抽出・統合・名寄せして
生成しています。生成手順や抽出条件の詳細は `build_geojson.py` 冒頭のコメントを
参照してください。

### stage_capability（対応ステージの目安）

AI相談との接続用に、各施設へ「どの進行段階の相談・受診に対応できそうか」の目安
`stage_capability`（`early` / `moderate` / `severe` の配列・複数該当可）を付与しています。

| 値 | 意味 | 判定条件（いずれか） |
|---|---|---|
| `early` | 鑑別・初期外来 | 認知症疾患医療センター / もの忘れ外来あり / 神経内科・脳神経内科・脳神経外科あり |
| `moderate` | 中等度・BPSD対応 | 認知症疾患医療センター / 精神病床あり / 精神科＋もの忘れ外来 |
| `severe` | 重度・長期/入院 | 認知症疾患医療センター / 療養病床あり / 精神病床あり |

- 病床数は医療情報ネットの病院票（01-1）の「療養病床」「精神病床」列（数値）で判定します。
  **診療所票（02-1）には精神病床の列が無いため 0 扱い**（＝診療所は病床条件では
  moderate/severe になりません。診療科・もの忘れ外来ベースの条件のみで判定されます）。
- 公開データからの機械的な推定であり、**受診可否の目安にすぎません**。地図上でも
  「目安です。受診前にご確認ください」と注記しています。
- 地図は `index.html?stage=early|moderate|severe` で該当施設を優先表示します
  （絞り込みではなく並び替え。既存の `flags` / `priority` パラメータと併用可）。

## 免責事項

- 表示される移動距離は2点間の**直線距離からの概算**です。実際の道路距離・所要時間
  とは異なります。
- 施設情報は変更されることがあります。**受診前には必ず施設に電話でご確認ください。**
- 住所検索には国土地理院ジオコーディングAPIを利用していますが、入力された住所は
  保存されません。

## ライセンス

本アプリが利用するデータの著作権は各データ提供元（厚生労働省、京都府）に帰属します。
データを再利用・転載する場合は、出典として「厚生労働省 医療情報ネット」および
「京都府 きょうと認知症あんしんナビ」を明記してください。

## ローカルでの再生成

元データ（医療情報ネットの全国版CSV4ファイル）を本リポジトリのルートに配置した上で、

```sh
python3 build_geojson.py               # 京都市内のみ（デフォルト: --scope city）
python3 build_geojson.py --scope pref  # 京都府全域版
```

を実行すると `clinics.geojson` を再生成できます。認知症疾患医療センターも
同じスコープで絞り込まれます（city の場合は京都市内のセンターのみ統合）。元データのCSVはサイズが大きいため
本リポジトリには含めていません（`.gitignore` 参照）。
